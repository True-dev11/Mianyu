# 眠屿 · 睡眠日记（Web + Android 0.2.0）

一个只属于自己的、轻量的睡眠日记。安卓优先设计，已有网页测试版和安卓 APK。

- 本地网页预览：<http://127.0.0.1:4180/>
- 同一 Wi‑Fi 下用安卓手机预览：查看电脑局域网 IP，然后访问 `http://<本机IP>:4180/`
- 若手机打不开网页预览，通常是 Windows 防火墙拦截了临时预览端口；先用电脑浏览器体验即可。

## 安卓 APK

- 本地构建产物：`release/Mianyu-0.2.0.apk`
- 包名：`com.mianyu.sleepdiary`
- 版本：0.2.0（versionCode 2）
- 大小：151,015 字节（约 148 KB）
- 支持：Android 6.0+（minSdk 23），targetSdk 35
- 安装、签名、数据和构建说明：[`release/README.md`](release/README.md)

注意：APK 的数据与网页测试的数据互相独立。首次安装会带 420 晚示例数据，正式使用前在 **设置 → 数据 → 清空示例**。

签名 keystore、`android/keystore.properties`、本机 SDK 路径和构建产物都不进入 Git；上传 GitHub 前请先阅读 [`GITHUB.md`](GITHUB.md)。

## 0.2.0 新增

- **夜醒次数**：记录睡眠时可直接加减夜间醒来次数，纳入评分和 AI 分析。
- **记录里的睡眠目标**：不用跳去设置，在记录弹窗里就能以 15 分钟为步长调整目标，保存后同步到全站评分。
- **睡眠月历**：日记页新增按评分着色的月历，可左右切换月份，点已有记录看详情，点过去空白日期直接补记。
- **规律度**：根据上床与醒来时间的综合波动计算，0–100。
- **睡眠达标率**：实际睡眠在目标 ±5 分钟内就算达标，显示百分比与达标晚数。
- 首页新增“夜醒”数据，趋势页新增规律度和达标率。

## 已实现的功能

### 睡眠记录
- 上床时间、醒来时间，自动计算在床时长与跨午夜时长。
- 入睡所需时间（0–120 分钟滑块和快捷值）。
- 夜醒次数（0–15 次步进）；选择 0 次时显示“一觉到天亮”。
- **实际睡眠时长自动计算**，也可以打开“自定义时长”手动校准。
- 醒来感受 1–5 级（很差 → 清爽），附对应表情。
- 睡前行为多选：刷手机、咖啡因、酒精、夜宵、运动、压力、阅读、冥想、热水澡、白天小睡。
- 可选备注；同一天只保留一条记录，可编辑、删除。
- 写入后即时更新评分、首页、趋势、月历和日记。

### 睡眠评分
- 每晚 0–100 分：睡眠时长（40）＋入睡速度（20）＋连续睡眠（10，按夜醒次数）＋醒来感受（20）＋作息规律（10）。
- 评分明细可以在“日记 → 任意一晚”里查看，共 5 项。
- 目标睡眠时长可以在设置里调整，也可以在记录弹窗里直接调整；修改后全站评分会重新计算。

### 趋势与日记
- 5 个区间：7 天 / 1 月 / 3 月 / 1 年 / 全部。
- 睡眠时长与睡眠评分双指标切换。
- 目标线、单晚悬浮详情、平均评分、平均睡眠、效率、睡眠达标率、平均上床/醒来、入睡耗时、作息规律度。
- 睡眠月历按每晚评分显示绿 / 黄 / 红三档颜色，空白日期仍可补记；下方显示当月规律度、达标率和平均评分。
- 每月规律度：上床与起床波动的综合值，满 3 晚显示，0–100 越高越规律。
- 每月睡眠达标率：睡眠时长在目标 ±5 分钟内即算达标，显示百分比和达标晚数。
- 行为与评分的描述性关联（明确标注不代表因果），不会给出医学诊断。
- 每晚都会生成可执行的本地建议；“AI 睡眠解读”可按需调用你自己的 API。
- 日记按月分组，可按区间筛选、分页加载、打开详情。

### 外观与布局
- 4 套皮肤：月白 / 雾青 / 沙丘 / 夜航，另加自定义底色。
- 6 个预设强调色，也可以自选任意颜色。
- 舒适 / 紧凑密度；柔和 / 利落圆角；“评分优先 / 建议优先”的首页顺序。
- 流畅动效开关；所有动画都尊重系统的“减少动态效果”设置。
- 扁平卡片、移动优先布局，桌面打开时是一个居中的手机画幅。

### AI（可选）
- 在 **设置 → AI 深度解读** 填入自己的 OpenAI 兼容接口：
  - API 地址（填到 `/v1`，或直接填完整的 `/chat/completions`）
  - 模型名称
  - API Key（本地服务可以留空）
- 支持“测试连接”，并可在趋势页生成解读；分析会带上夜醒次数、规律度和达标率。
- 请求只包含睡眠统计和最近记录，不包含昵称、备注和 API Key。
- API Key 只保存在本机；导出的 JSON 备份不包含 Key。
- 网页版是浏览器直连 API，因此服务端需要允许 CORS；安卓 APK 改用原生 HTTP 请求，绕开了这个限制。
- 安卓版的导入/导出通过系统文件选择器完成，不需要存储权限；硬件返回键会优先关闭弹窗。

### 数据
- 所有记录保存在 `localStorage`，键名：`mianyu.sleep.v1`。
- 支持 JSON 导出 / 导入；导入会替换当前记录，但保留本机的 API Key。
- 初次打开包含 420 晚示例数据，方便查看趋势和月历。示例数据可以一键清空，也可以在没有记录时重新载入。
- 旧版本中没有夜醒字段的记录会按 0 次处理；旧版示例数据会自动补齐夜醒次数。
- 换手机前请先导出备份。

## 运行方式

```powershell
cd path\to\sleep-app
python -m http.server 4180 --bind 0.0.0.0
```

或者双击 / 运行：

```powershell
.\serve.ps1
```

然后打开 <http://127.0.0.1:4180/>。项目没有构建步骤、没有 npm 依赖，源文件即成品。

## 说明

- Android APK 已生成，数据与网页预览相互独立。
- AI 接口按 OpenAI Chat Completions 格式实现；如果你常用的服务不是这种格式，需要调整。
- 评分和建议用于自我观察，不替代医疗诊断。
- 后续修改网页源码后，运行 `.\build-apk.ps1` 可重新出包；升级时务必递增 `versionCode` 并使用同一把 keystore。
